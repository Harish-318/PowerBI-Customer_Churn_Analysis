# 📊 Customer Churn Analysis Dashboard | Power BI

An interactive **Customer Churn Analysis Dashboard** built using **Microsoft Power BI** to analyze customer behavior, churn patterns, services, contracts, billing, and revenue impact.

---

## 🎯 Project Objective

The objective of this project is to identify the **key factors influencing customer churn** and provide actionable insights to support **customer retention and revenue improvement**.

---

## 🛠️ Tools & Technologies

| Tool / Technology | Purpose |
|---|---|
| **Microsoft Power BI** | Dashboard development and data visualization |
| **Power Query** | Data transformation and preparation |
| **DAX** | Calculated measures and KPIs |
| **Data Modeling** | Structuring data for analysis |
| **Interactive Slicers** | Dynamic filtering and exploration |

---

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| **Total Customers** | **7,032** |
| **Churned Customers** | **1,869** |
| **Churn Rate** | **26.58%** |
| **Average Tenure** | **32.42** |
| **Avg. Monthly Charges** | **64.80** |
| **Total Revenue** | **16.06M** |
| **Lost Revenue** | **2.86M** |

---

## 📑 Dashboard Pages

The report contains **5 interactive pages**:

### 1. 📊 Executive Dashboard
Overall customer and churn performance.

### 2. 👥 Customer Demographics Analysis
Analysis of customer segments, demographics, and tenure.

### 3. 📡 Service Subscription Analysis
Analysis of services and their relationship with customer churn.

### 4. 💳 Contract & Billing Insights
Analysis of contracts, payment methods, and billing patterns.

### 5. 🎯 Churn Prediction & Key Drivers
Analysis of major churn drivers and their revenue impact.

---

## 🔍 Key Insights

- Overall customer churn rate is **26.58%**.
- **Month-to-month contracts** have a significantly higher churn rate.
- Churn varies across different **tenure groups and internet services**.
- Customer churn resulted in approximately **2.86M in lost revenue**.
- **Contract type, service subscriptions, and billing behavior** are important factors for customer retention.

## 🚀 How to Use

1. Download the **Customer_Churn_Analysis.pbix** file from the **PowerBI** folder.
2. Open the file using **Microsoft Power BI Desktop**.
3. Navigate through the **five interactive dashboard pages**.
4. Use the available **slicers** to explore customer segments, churn rates, revenue, and other KPIs.
5. Use the dashboard visuals to analyze customer churn patterns and key churn drivers.

> **Note:** Microsoft Power BI Desktop is required to open the `.pbix` file.
